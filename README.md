# XenaReco - OSINT Recon Tool 🕵️‍♂️

XenaReco es una herramienta de **reconocimiento OSINT** que permite obtener información de dominios de forma rápida y sencilla.

## 🔍 Características:
✅ WHOIS del dominio  
✅ Dirección IP del servidor  
✅ Encabezados HTTP del sitio web  
✅ Scraping de meta información (Título y Descripción)  

## 🚀 Cómo usarlo
### 1️⃣ Clonar el repositorio:
```bash
git clone https://github.com/XenaMVPs/XenaReco.git
cd XenaReco
```

### 2️⃣ Instalar dependencias:
```bash
pip install flask requests whois bs4
```

### 3️⃣ Ejecutar la aplicación:
```bash
python app.py
```

### 4️⃣ Abrir en el navegador:
👉 **http://127.0.0.1:5000/**  

Introduce un dominio y obtendrás información detallada en segundos. 🚀
